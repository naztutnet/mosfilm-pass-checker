# Журнал проверок

Журнал хранится в закрытой Google-таблице. В него попадают только:

- время на сервере;
- введённая фамилия;
- результат проверки;
- случайный идентификатор вкладки браузера.

IP-адрес и данные об устройстве сайт намеренно не собирает. Запись показывает,
какую фамилию ввели, но не подтверждает личность посетителя.

## Подключение

1. Создайте пустой проект на [script.google.com](https://script.google.com/).
2. Вставьте содержимое `Code.gs`.
3. Запустите функцию `setup` и разрешите доступ. Она создаст закрытую таблицу
   **«Журнал проверок пропуска на Мосфильм»** в Google Drive.
4. Выберите **Развернуть → Новое развертывание → Веб-приложение**.
5. Выполнять от имени владельца. Доступ: любой пользователь.
6. Скопируйте URL веб-приложения в `assets/log-config.js`.

URL веб-приложения не является секретом. Публичный статический сайт не может
надёжно доказать личность посетителя или полностью защитить журнал от спама.
