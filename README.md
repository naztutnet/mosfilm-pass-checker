# Проверка заявки на пропуск Мосфильм

Одностраничный сайт для проверки, включена ли фамилия в заявку на квартальный пропуск на «Мосфильм».

Логотип в `assets/mosfilm-logo.svg` взят из SVG-спрайта официального сайта [mosfilm.ru](https://www.mosfilm.ru/).

## Как работает

- Проверка выполняется прямо в браузере.
- В репозитории нет ФИО, телефонов, паспортных данных или исходного DOCX.
- В `assets/pass-hashes.js` хранятся только SHA-256 хэши нормализованных фамилий.
- Пока журнал отключён, сайт не отправляет введённые данные на сервер и не использует аналитику.
- После подключения журнала сайт отправляет введённую фамилию, результат и
  идентификатор сессии в закрытую Google-таблицу. Это явно указано под формой.

Важно: хэширование уменьшает риск случайного раскрытия списка, но публичный статический сайт не обеспечивает строгую защиту от перебора распространённых фамилий. Для закрытого списка нужен серверный API с ограничением запросов.

## Обновление списка

Запустите генератор, передав путь к новому DOCX:

```bash
python scripts/build_pass_hashes.py /path/to/list.docx --out assets/pass-hashes.js
```

Генератор ищет фамилии между фразами `следующим сотрудникам` и `С уважением`, проверяет дубли и публикует только хэши.

## Контакты

Telegram указан непосредственно в `index.html`. Телефон настраивается полями `phoneDisplay` и `phoneHref` в `assets/pass-hashes.js`.

## Журнал проверок

Код и инструкция находятся в `google-apps-script/`. Пока `endpoint` в
`assets/log-config.js` пуст, журнал отключён и данные никуда не отправляются.
